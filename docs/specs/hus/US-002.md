# US-002: User Login

## As a registered user, I want to log in and receive a JWT so I can authenticate subsequent requests.

## Given / When / Then

- **Given** a registered user with a valid email and password.
- **When** the user submits a POST request to `/api/auth/login`.
- **Then** a JWT token is returned for subsequent authenticated requests (HTTP 200).

## Acceptance Criteria

1. POST `/api/auth/login` returns a JWT containing `sub` (userId), `tenantId`, and `exp`.
2. The token is signed with the key from `${JWT_SECRET}`.
3. Returns `401` (RFC 7807) when credentials are invalid.
4. The token's `tenantId` claim is used by `JwtAuthFilter` for all subsequent request authorization.
5. The `Authorization` header format is `Bearer <token>`.
6. The token expiration (`exp`) is enforced; expired tokens return `401`.

## Out of Scope

- OAuth2 social login (v1.0).
