# US-006: AI Metadata Generation

## As an authenticated user, I want the system to automatically generate a title and description for my video so I don't have to write them manually.

## Given / When / Then

- **Given** a video in `RECEIVED` status has been stored in object storage.
- **When** the system invokes the AI metadata generation pipeline (Gemini adapter).
- **Then** a `title` and `description` are produced and the video transitions to `PROCESSING` → `UPLOADING` status.

## Acceptance Criteria

1. The `AITextGenerationPort.generateTitleAndDescription(FileMetadata)` method is called with the video's `FileMetadata`.
2. Gemini processes the request and returns a `title` and `description`.
3. The video `status` transitions from `RECEIVED` to `PROCESSING` to `UPLOADING`.
4. On success, `VideoEntity.title` and `VideoEntity.description` are populated.
5. On Gemini failure (circuit breaker OPEN or max retries exhausted):
   - **Fallback title**: `"Title for {filename}"`
   - **Fallback description**: `"Description for {filename}"`
   - The upload proceeds with placeholder metadata (non-fatal).
6. Fallback events are logged at WARN level with the video `videoId` and `filename`.
7. `gemini.latency` metric is emitted per request.
8. The `GeminiAdapter` uses Resilience4j circuit breaker (50% failure over 10s, 60s wait) and exponential backoff retry (3 attempts, 1s–30s).
