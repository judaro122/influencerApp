# US-003: Link YouTube Channel via OAuth2

## As an authenticated user, I want to link my YouTube channel via OAuth2 so the system can upload to it.

## Given / When / Then

- **Given** an authenticated user with a valid JWT.
- **When** the user initiates a YouTube channel registration via POST `/api/channels/register` with an OAuth2 authorization code.
- **Then** the system exchanges the code for tokens, encrypts and stores them, and returns the linked channel details (HTTP 201).

## References

- **API Contract**: `docs/specs/arq/openapi.yaml` — `/api/channels/register` (POST) endpoint and `/api/channels` (GET) endpoint.
- **Data Model**: `docs/specs/arq/data-model.md` — `Channel` aggregate (§2.1), `ChannelEntity` table schema (§3.2), `ChannelRegistrationRequest` and `ChannelResponse` DTOs (§5.3, §5.4).
- **Security**: `docs/specs/security-spec.md` — Token encryption with AES/GCM (§4), key source `${ENCRYPTION_KEY}` → `${JWT_SECRET}` fallback.
- **Integrations**: `docs/specs/integrations-spec.md` — YouTube OAuth2 flow (§4.1), token refresh (§4.2), circuit breaker (§4.3), and retry policy (§4.4).
- **Constitution**: §2.5 — Secrets never in code; tokens encrypted at rest. §4.4 — Only `youtube.upload` scope requested.

## Acceptance Criteria

1. POST `/api/channels/register` accepts an OAuth2 `authCode`.
2. The system exchanges the auth code with Google for `access_token` and `refresh_token`.
3. Tokens are encrypted with AES/GCM/NoPadding before storage (security-spec §4).
4. The `channels` table stores encrypted tokens in `bytea` columns (`access_token_enc`, `refresh_token_enc`).
5. The returned `ChannelResponse` includes `channelId`, `youtubeChannelId`, `youtubeChannelTitle`, and `scope`.
6. The `tenantId` from the JWT is associated with the channel; cross-tenant linking is forbidden.
7. Only `https://www.googleapis.com/auth/youtube.upload` scope is requested (constitution §4.4).

## Out of Scope

- Revoking channel access (v1.0).
- Linking multiple channels in a single request (v1.0, out of scope per constitution §11.6).
