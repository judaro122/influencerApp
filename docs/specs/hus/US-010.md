# US-010: Receive Notification When Video Is Published

## As an authenticated user, I want to receive a notification when my video is published so I can share it.

## Given / When / Then

- **Given** a video has been successfully published to YouTube (status `PUBLISHED`).
- **When** the `video-published` Kafka event is produced and consumed.
- **Then** the user is notified that the video is live and can access its YouTube URL.

## References

- **Kafka Schema**: `docs/specs/arq/kafka-events.md` — `video-published` event schema (§4.3), topic (`video-published`), DLQ routing (§6).
- **Data Model**: `docs/specs/arq/data-model.md` — `VideoStatusResponse` DTO (§5.2) with `youtubeVideoId`, `youtubeUrl`, and `status = PUBLISHED`.
- **API Contract**: `docs/specs/arq/openapi.yaml` — GET `/api/videos/{videoId}` (US-008) returns `VideoStatusResponse` including `youtubeUrl`.
- **Architecture**: `docs/specs/arq/architecture.md` — `YouTubeUploadPort` (§7.2), `VideoPublishedEvent` (§6.2), tenant-scoped Kafka consumption (§6.4).
- **Constitution**: §2 — Multi-tenancy by default; every Kafka payload includes `tenantId`. §4.4 — Eventual consistency; no synchronous wait for YouTube publish.

## Acceptance Criteria

1. When a video transitions to `PUBLISHED` status, a `video-published` Kafka event is emitted with `youtubeVideoId` and `youtubeUrl` (kafka-events.md §4.3).
2. The user can retrieve the publish status and YouTube URL by polling GET `/api/videos/{videoId}` (see US-008).
3. The notification includes: `videoId`, `title`, `youtubeUrl`, and `publishedAt` timestamp.
4. The notification is scoped to the requesting tenant only (cross-tenant notification is forbidden).
5. If publishing fails, the video status is `FAILED` and `errorReason` is populated; no notification is sent.
6. The Kafka consumer is idempotent: duplicate `video-published` events do not send duplicate notifications.

## Out of Scope

- Real-time push notifications via WebSocket or SSE (v1.0, out of scope per constitution §11.4).
- Webhook callbacks for real-time client notifications (v1.0, out of scope per constitution §11.7).
