# US-004: View Linked Channels

## As an authenticated user, I want to view my linked channels so I know which ones are available.

## Given / When / Then

- **Given** an authenticated user who has previously linked at least one YouTube channel.
- **When** the user sends a GET request to `/api/channels`.
- **Then** a paginated list of the user's linked channels is returned (HTTP 200).

## Acceptance Criteria

1. GET `/api/channels` returns HTTP 200 with a paginated `ChannelListResponse`.
2. Only channels belonging to the requesting tenant (`tenantId` from JWT) are returned.
3. Response includes `content`, `page`, `size`, `totalElements`, and `totalPages`.
4. Each channel item includes `channelId`, `youtubeChannelId`, `youtubeChannelTitle`, `scope`, and `createdAt`.
5. Returns `401` (RFC 7807) when no valid JWT is provided.
6. Returns empty `content` array with `totalElements: 0` when the user has no linked channels.

## Out of Scope

- Channel unlinking/deletion (v1.0).
- Sorting or filtering channels (v1.0).
