# US-001: User Registration

## As a new user, I want to register an account so I can access the service.

## Given / When / Then

- **Given** a new user with a valid email and password.
- **When** the user submits a POST request to `/api/auth/register`.
- **Then** a new user account is created and a response with `{id, email}` is returned (HTTP 201).

## Acceptance Criteria

1. POST `/api/auth/register` creates a user with a unique email.
2. Returns `400` (RFC 7807) when email is missing or malformed.
3. Returns `409` (RFC 7807) when the email is already registered.
4. Password is stored hashed (never plaintext).
5. Response includes the generated user `id` and `email` only.
6. Tenant isolation: Each registered user has an associated `tenantId`.

## Out of Scope
